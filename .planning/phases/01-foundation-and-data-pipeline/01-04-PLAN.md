<task type="auto">
  <name>Task 2: GitHub REST client for repo enumeration, commits, and languages</name>
  <files>
    worker/src/github/rest.ts
  </files>
  <action>
    Create the REST client with pagination, rate limit handling, and all needed fetch operations.

    **worker/src/github/rest.ts:**

    Import `Octokit` from `@octokit/rest`. Import types from `./types.ts`.

    **Helper: structured logging**
    ```typescript
    function log(stage: string, data: Record<string, unknown>) {
      console.log(JSON.stringify({ stage, ...data, ts: Date.now() }));
    }
    ```

    **Helper: rate limit check**
    Create a `checkRateLimit(octokit: Octokit)` function:
    - Call `octokit.rateLimit.get()`
    - Log remaining/limit for both `core` (REST) and `graphql` resources
    - Return { remaining: number, resetAt: Date } for the `core` resource
    - If remaining < 100, log a warning

    **Export `createOctokit(token: string): Octokit`**
    - Creates Octokit instance with auth token
    - MUST be called inside handler context, not module scope

    **Export `fetchAllRepos(octokit: Octokit): Promise<GitHubRepo[]>`**
    - Use `octokit.paginate(octokit.repos.listForAuthenticatedUser, { affiliation: "owner,collaborator,organization_member", per_page: 100 })`
    - This automatically handles pagination via Link headers
    - Log total repo count after fetching
    - Per user decision: includes owned, org, and forked repos (the affiliation filter covers this)

    **Export `fetchRepoLanguages(octokit: Octokit, owner: string, repo: string): Promise<Record<string, number>>`**
    - Call `octokit.repos.listLanguages({ owner, repo })`
    - Return the data object (language name -> byte count)

    **Export `fetchRepoCommits(octokit: Octokit, owner: string, repo: string, author: string, since: string, until?: string): Promise<GitHubCommit[]>`**
    - Use `octokit.paginate(octokit.repos.listCommits, { owner, repo, author, since, until, per_page: 100 })`
    - Returns list of commits (sha, message, date) -- does NOT include stats
    - Log commit count per repo

    **Export `fetchCommitDetail(octokit: Octokit, owner: string, repo: string, ref: string): Promise<GitHubCommitDetail>`**
    - Call `octokit.repos.getCommit({ owner, repo, ref })`
    - Returns full commit with stats (additions, deletions)
    - This is the N+1 call from research Pitfall 1 -- only called for public repos' recent commits
    - Check rate limit before each call; if remaining < 200, stop fetching details and log warning

    **Rate limit strategy (per research):**
    - REST and GraphQL have separate 5,000/hr pools
    - Reserve 80% of REST budget (4,000 calls) for commit detail fetches
    - Check X-RateLimit-Remaining after batches of API calls
    - If approaching limit (<200 remaining), log warning and skip remaining commit detail fetches (graceful degradation)
    - Never throw on rate limit -- log and continue with what we have
