  <behavior>
    **sanitizePrivateRepo(raw, monthlyCommits, languages):**
    - Input: raw GitHub repo object (full_name, private, fork, parent, created_at, pushed_at), monthly commits map, languages map
    - Output: ProjectEntry with ONLY allowed fields
    - id = SHA-256 hash of full_name, first 16 hex chars
    - name = "Private Repo" (always, regardless of actual name)
    - isPrivate = true
    - isFork = raw.fork
    - parentRepo = { name: parent.full_name, url: parent.html_url } ONLY if raw.fork AND parent exists AND parent is NOT private. Otherwise null.
    - languages = Object.keys(languages) (names only, no byte counts)
    - createdAt = raw.created_at sliced to "YYYY-MM-DD"
    - lastActiveAt = raw.pushed_at sliced to "YYYY-MM-DD"
    - monthlyCommits = passed through
    - totalCommits = sum of monthlyCommits values
    - MUST NOT include: url, description, topics, recentCommits
    - CRITICAL TEST: JSON.stringify the output and verify it does NOT contain the original repo full_name or html_url

    **transformRepo(raw, monthlyCommits, languages, recentCommits?):**
    - For public repos: includes all ProjectEntry fields including url, description, topics, recentCommits
    - For private repos: delegates to sanitizePrivateRepo
    - id for public repos = String(raw.id) (GitHub numeric ID)

    **filterRepos(repos):**
    - Filters out repos with totalCommits < 3
    - Input: ProjectEntry[] -> Output: ProjectEntry[]

    **transformContributionCalendar(calendar):**
    - Input: GitHub GraphQL contributionCalendar shape { totalContributions, weeks: [{ contributionDays: [{ contributionCount, contributionLevel, date }] }] }
    - Output: GraphData { days, totalContributions, rangeStart, rangeEnd }
    - Maps contributionLevel enum to integer: NONE->0, FIRST_QUARTILE->1, SECOND_QUARTILE->2, THIRD_QUARTILE->3, FOURTH_QUARTILE->4
    - days = flat array of ContributionDay from all weeks
    - rangeStart = first day's date, rangeEnd = last day's date

    **isBackfillNeeded(meta):**
    - Input: PipelineMeta | null
    - Output: boolean
    - null (no meta.json in R2) -> true
    - meta.lastUpdated older than 48 hours -> true
    - Otherwise -> false
  </behavior>
