    **Part A: Squircle (superellipse) clip-path**

    A true squircle / superellipse cannot be achieved with `border-radius` alone (which produces a "squashed circle" / standard rounded rect). Use a CSS `clip-path: path(...)` with a superellipse SVG path, or `clip-path: polygon(...)` approximating a squircle.

    The recommended approach: define a clip-path using a smooth superellipse polygon approximation. Add a reusable class in `main.css` `@layer components`:

    ```css
    .squircle {
      clip-path: path('M 0.5,0 C 0.785,0 1,0.215 1,0.5 C 1,0.785 0.785,1 0.5,1 C 0.215,1 0,0.785 0,0.5 C 0,0.215 0.215,0 0.5,0 Z');
    }
    ```

    HOWEVER: `clip-path: path()` uses absolute coordinates, not relative. For responsive images, the better approach is `clip-path: url(#squircle)` referencing an inline SVG `<clipPath>` with `clipPathUnits="objectBoundingBox"`, or use a hardcoded polygon approximation.

    **BEST approach for responsive squircle:** Use an inline SVG clipPath definition in the component with `clipPathUnits="objectBoundingBox"` and reference it via `clip-path: url(#squircle-clip)`. The superellipse path should use n~4 (a true squircle has n=4 in the superellipse formula |x/a|^n + |y/b|^n = 1).

    Generate the squircle path points for `clipPathUnits="objectBoundingBox"` (coordinates 0-1):
    A good superellipse approximation with n=4:
    ```
    M 0.5 0
    C 0.81 0, 1 0.19, 1 0.5
    C 1 0.81, 0.81 1, 0.5 1
    C 0.19 1, 0 0.81, 0 0.5
    C 0 0.19, 0.19 0, 0.5 0
    Z
    ```

    For a MORE pronounced squircle (user wants "more squircle"), push the control points further toward corners. A more pronounced shape (closer to square with rounded corners, but still smooth):
    ```
    M 0.5 0
    C 0.875 0, 1 0.125, 1 0.5
    C 1 0.875, 0.875 1, 0.5 1
    C 0.125 1, 0 0.875, 0 0.5
    C 0 0.125, 0.125 0, 0.5 0
    Z
    ```

    Add a hidden SVG with the clipPath definition at the top of the Hero component (or in App.tsx), and apply `style={{ clipPath: 'url(#squircle-clip)' }}` to the photo wrapper/img.

    Apply the squircle to BOTH the real photo in Hero.tsx AND the photo skeleton shape in HeroSkeleton.tsx so the loading state matches the loaded state shape.

    Replace the skeleton shimmer for the photo with a LQIP pattern:

    1. The LQIP approach: Show a tiny (e.g., 20x25px) blurred version of the headshot as a base64-encoded data URI or a small file, then fade to the full-res image when it loads.

    2. Implementation in Hero.tsx:
       - Add state: `const [imageLoaded, setImageLoaded] = useState(false)`
       - Render a container div with the squircle clip-path applied
       - Inside the container, render BOTH the LQIP placeholder and the full-res image stacked on top of each other (using absolute positioning)
       - The LQIP placeholder: an `<img>` with a tiny blurred source (inline base64 data URI of a ~20x25px WebP/JPEG) and CSS `filter: blur(20px)` + `transform: scale(1.1)` (scale prevents blur edge artifacts)
       - The full-res image: an `<img>` with `onLoad={() => setImageLoaded(true)}` that transitions opacity from 0 to 1
       - When `imageLoaded` is true, the full-res image fades in over ~300-500ms, covering the blur

    3. Add LQIP transition styles in main.css `@layer components`:
       ```css
       .lqip-container {
         position: relative;
         overflow: hidden;
       }

       .lqip-placeholder {
         width: 100%;
         height: 100%;
         object-fit: cover;
         filter: blur(20px);
         transform: scale(1.1);
       }

       .lqip-full {
         position: absolute;
         inset: 0;
         width: 100%;
         height: 100%;
         object-fit: cover;
         opacity: 0;
         transition: opacity 500ms ease;
       }

       .lqip-full.loaded {
         opacity: 1;
       }
       ```
