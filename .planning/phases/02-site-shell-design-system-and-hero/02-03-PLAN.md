       ```json
               "methods": ["GET", "HEAD"],

             },

           }
         ]
       }
       ```

    2. Apply the CORS update to R2:
       ```bash
       npx wrangler r2 bucket cors set jacklabbe-data --file cors.json
       ```
       If this fails with auth error, note it and proceed to deployment (auth gate will be handled dynamically).

    3. Build the site for production:
       ```bash
       cd site && pnpm build
       ```
       Verify the dist/ directory contains index.html and assets.

    4. Deploy to Cloudflare Pages:
       ```bash
       cd site && npx wrangler pages deploy dist --project-name=jacklabbe
       ```
       If the project doesn't exist, it will be created on first deploy. Capture the deployment URL (will be something like https://xxx.jacklabbe.pages.dev or https://jacklabbe.pages.dev).

    5. If deployment succeeds, record the .pages.dev URL for the verification checkpoint.
