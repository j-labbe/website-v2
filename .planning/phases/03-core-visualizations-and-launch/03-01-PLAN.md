Create `commitGraphUtils.ts`:
- Define constants: CELL_SIZE=13, CELL_GAP=3, CELL_RADIUS=2, LABEL_OFFSET (for day-of-week labels ~30px), MONTH_LABEL_HEIGHT (~20px)
- Define LEVEL_COLORS array: level 0 = '#0a1628' (near-background faint fill), level 1 = '#0e3460', level 2 = '#1a6dbd', level 3 = '#3b8eea', level 4 = '#4F7DF5' (matches --color-accent)
- Export `dayToCellPosition(day: ContributionDay, rangeStart: string): CellPosition` -- maps a ContributionDay to weekIndex + dayIndex. CRITICAL: use UTC date methods (`getUTCDay()`, `getUTCFullYear()`) consistently to avoid timezone shifting (see research pitfall 2). Parse dates by appending 'T00:00:00Z' or use UTC methods throughout.
- Export `getColumnDelay(weekIndex: number, totalWeeks: number): string` -- returns animation-delay in ms (spread over ~1.5s total)
- Export `formatTooltipText(count: number, date: string): string` -- returns "12 commits on Jan 15, 2026" format. Use `Intl.DateTimeFormat` with UTC timezone to avoid date shift.
- Export `getMonthLabels(cells: CellPosition[], rangeStart: string): { label: string; weekIndex: number }[]` -- computes month label positions by finding the first weekIndex where each month starts. Labels: "Jan", "Feb", etc.

Create `CommitGraphTooltip.tsx`:
- Props: `{ visible: boolean; x: number; y: number; text: string }`
- Render a div with `absolute pointer-events-none` positioning, bg-surface-2 border-border, text-xs, rounded-md, z-10
- Position using `left: x`, `top: y - 40` (above the cell), `transform: translateX(-50%)` to center
- Return null if not visible

Create `CommitGraph.tsx`:
- Props: `{ data: GraphData }` -- receives graph data from parent
- Map `data.days` through `dayToCellPosition` to get all cell positions
- Compute SVG viewBox dimensions from cell positions + labels + legend space
- Render `<svg>` with `role="img"` and `aria-label="Commit activity over the past year"`
- Render month labels along top using `<text>` elements (fill text-dim color, font-size 10, font-family mono)
- Render day-of-week labels on left: "Mon", "Wed", "Fri" at dayIndex 1, 3, 5 (same style as month labels)
- Render cells as `<rect>` elements with fill from LEVEL_COLORS[cell.level], rx=CELL_RADIUS
- Each cell gets className="commit-cell" and style={{ animationDelay: getColumnDelay(weekIndex, totalWeeks) }} for wave animation
- Mouse event handlers on each rect: onMouseEnter sets tooltip state (visible, x computed from cell's SVG position mapped to container DOM coords, y, formatted text), onMouseLeave hides tooltip. Use the container ref's getBoundingClientRect() plus the cell's relative position for tooltip placement (avoid SVG coordinate pitfall from research).
- Render "Less -- More" legend in bottom-right: a row of 5 small rects (one per level) with "Less" text before and "More" text after, using same LEVEL_COLORS
- Wrap the SVG in a `div` with `relative overflow-x-auto` for mobile horizontal scroll (GRPH-05). Add `-webkit-overflow-scrolling: touch` via className for smooth mobile scrolling.
- NO section heading -- graph flows naturally below hero per user decision
- Empty cells have faint fill (level 0 color) to show full grid structure per user decision

SVG hover: For cell scale on hover, use CSS with `transform-box: fill-box; transform-origin: center;` on .commit-cell (research confirms modern browser support). Scale to 1.8x per user decision (1.5-2x range). Transition 120ms ease per user spec.
